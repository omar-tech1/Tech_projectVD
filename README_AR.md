# منصة علوم الحاسب — نسخة HTML مباشرة

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` بالنقر عليه مرتين في المتصفح.

لا تحتاج إلى Python أو تثبيت أي مكتبات أو تشغيل سيرفر محلي.

## ملاحظات

- ملفات الفيديو موجودة داخل مجلد `videos` وتعمل مباشرة من الجهاز، من دون YouTube أو اتصال بالإنترنت.
- خط Cairo يُحمّل من الإنترنت؛ إذا لم يتوفر الاتصال يستخدم الموقع خطًا بديلًا.
- تقدم الاختبارات يُحفظ في المتصفح إن كان المتصفح يسمح بالتخزين عند فتح الملفات مباشرة. إذا لم يُحفظ، سيظل بإمكانك استخدام المنصة أثناء فتح الصفحة.
- اترك `index.html` و`styles.css` و`app.js` و`favicon.svg` ومجلد `videos` معًا في المجلد نفسه.
- لا تنقل ملفات MP4 خارج مجلد `videos` ولا تغيّر أسماءها.
